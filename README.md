## Requisitos

- LabVIEW 2026 (los VIs están guardados con la versión 26).
- Al abrir los VIs por primera vez, LabVIEW puede pedir marcar la carpeta como de confianza (*trusted*). Si no se acepta, `SubVI_Integrator.vi` aparece como no ejecutable y el VI principal queda roto.
